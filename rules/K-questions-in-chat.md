## §K — Questions in the chat text

Ask questions in the chat text, so the developer can read the whole chat and answer in one line
such as "1A, 2B". Never use the option-selection box (AskUserQuestion): it hides the chat while the
developer prepares the answer.

- Number the questions (1, 2, 3…) and write each option out in full (A, B…).
- Mark the recommended option and say why in one line (§B item 1).
- Ask only questions whose answer changes the outcome. The questions the RSCT rules, prompts and
  tools require are always asked, in the form they give (for example §F's permission and
  reversibility questions, the questions of a setup report, or a question a tool result tells
  you to ask).
- The RSCT approval windows (the Yes/No dialogs of commit, push, merge and the phase gates) are not
  the option-selection box: they are required and stay.
